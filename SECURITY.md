# Security Policy

## Reporting Security Issues

We take data integrity and software security seriously. Because this project produces reference linguistic data consumed by AI systems, data poisoning, malicious prompt injections, or script vulnerabilities are considered security issues.

### Scope
- **Data Integrity**: Intentional injection of malicious prompt overrides, adversarial text, or corrupt Unicode payloads into dataset files.
- **Code & Tooling**: Security vulnerabilities in validation scripts, build tools, MCP servers, or CI workflows.

### How to Report
Please **do not** report sensitive security vulnerabilities via public GitHub issues. Instead:
- Use GitHub Private Vulnerability Reporting on the repository, or
- Contact the project maintainers directly.

You will receive an initial response within 48 hours, followed by updates on investigation and remediation.
